# VeilGram для iPhone

Неофициальный нативный клиент на базе [Telegram-iOS](https://github.com/TelegramMessenger/Telegram-iOS). Минимальная версия для этой ветки — iOS 15.0.

- **Удалённые сообщения.** Когда клиент получает удаление уже загруженного входящего сообщения, он оставляет локальную копию на её месте. Пузырь полупрозрачный, рядом со временем есть корзина. Поддерживаются обычные личные чаты и группы, включая супергруппы. Копируются текст и подписи, а обычные вложения открываются из доступного кэша. Секретные чаты, сообщения с таймером, защищённый контент и сообщения, которых клиент ещё не получил, исключены.
- **Баннер профиля.** В меню **Оформление VeilGram** можно выбрать фото, GIF или видео для фона за аватаркой. GIF с большим числом кадров сжимается при импорте. Для видео используются первые 12 секунд без звука. Цвет ника выбирается из палитры iOS.
- **Визуальные подарки.** В штатной вкладке **Подарки** профиля есть витрина VeilGram. Добавь NFT по ссылке или удержи настоящий коллекционный подарок и выбери **В витрину VeilGram**. На экране отправки обычного подарка под оплатой Telegram есть кнопка **Отправить визуально** с отдельным пополняемым балансом VeilGram. VeilGram показывает подарок карточкой в личном чате и во вкладке **Подарки** получателя. В других клиентах Telegram видно текстовое сообщение с названием.
- **Оформление и голосовые.** Когда человек делится профилем через VeilGram, получатель видит значок у его имени в профиле и в личном чате. В настройках оформления есть дополнительная палитра чата и смена иконки приложения. Обычные загруженные голосовые можно расшифровывать средствами iPhone, если на устройстве доступно распознавание для текущего языка. Плашка VeilGram видна в самом приложении под камерой в портретной ориентации на моделях с высокой верхней областью экрана.

## Сборка с Windows и установка на iPhone

Пока проект содержит исходники и сценарий сборки. Готовый `.ipa` появится после успешной сборки на macOS.

1. Получите свои `api_id` и `api_hash` в разделе **API development tools**. [Инструкция Telegram](https://core.telegram.org/api/obtaining_api_id).
2. Загрузите проект вместе с `.github/workflows/ios.yml` в свой репозиторий GitHub. В **Settings → Secrets and variables → Actions** добавьте секреты `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`.
3. В **Actions → Build VeilGram for iPhone** нажмите **Run workflow**. После успешной сборки скачайте артефакт `VeilGram-unsigned` и распакуйте `VeilGram-unsigned.ipa`.
4. Установите AltStore Classic через AltServer на Windows. Перенесите `.ipa` в приложение **Файлы** на iPhone и выберите его в **AltStore → My Apps → +**. AltStore подпишет и установит приложение. На iOS 16 и новее включите режим разработчика. С бесплатной учётной записью подпись нужно обновлять каждые семь дней. [Установка AltStore на Windows](https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows) · [Обновление подписи](https://faq.altstore.io/altstore-classic/your-altstore).

Можно собрать тот же `.ipa` на Mac с Xcode 27.1. Установите `ccache` и компонент `MetalToolchain` командой `xcodebuild -downloadComponent MetalToolchain`. Укажите `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` в переменных окружения и запустите команду из папки проекта.

```sh
python3 scripts/build_ios.py ipa
```

Результат появится в `out/VeilGram-unsigned.ipa`. Для генерации проекта Xcode запустите `python3 scripts/build_ios.py xcode` с переменной `APPLE_TEAM_ID` вашей команды. В сборке для AltStore отключены расширения приложения.

Если iOS разрешила уведомления, VeilGram может показать локальное уведомление о новом сообщении, полученном во время фоновой синхронизации. Для доставки при закрытом приложении нужен профиль подписи с правом APNs и настройка APNs для приложения Telegram. В Xcode задайте `VEILGRAM_APS_ENVIRONMENT=development` или `production` согласно профилю подписи.

## Обмен через Telegram

Оформление хранится на iPhone. Открой профиль другого человека и нажми **Отправить свой профиль VeilGram**. В личный чат придёт обычное вложение с баннером, цветом, статусом и витриной. Чтобы передать обновлённое оформление, отправь профиль ещё раз.

Мод привязывает вложение к отправителю обычного личного сообщения. Подарки видны получателю после открытия своего профиля. Бот, отдельный сервер и регистрация для обмена не нужны. Копии удалённых сообщений и расшифровки VeilGram хранятся в локальной базе клиента.

## Общий профиль и архив на хостинге

Для отдельного сервиса нужен Node.js 24 или новее, постоянный каталог `data` и HTTPS. Загрузите файлы из `server`, установите зависимости командой `npm ci` и запустите `npm start`. Путь к сертификату и ключу задаётся в `TLS_CERT` и `TLS_KEY`, если HTTPS завершается в самом Node.js. Для сборки с закреплённым сертификатом укажите адрес в `VEILGRAM_HOSTED_URL` и SHA-256 сертификата в `VEILGRAM_CERTIFICATE_SHA256`.

Укажите токен бота в `TELEGRAM_BOT_TOKEN`. В VeilGram откройте **Настройки → Сервер VeilGram**, запросите у бота код командой `/code` и подключите профиль. На сервере хранится одна текущая версия оформления на аккаунт.

**Настройки → Удалённые сообщения** показывает локальные копии и записи подключённого сервера. Для записи при закрытом приложении задайте на хостинге `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` и случайный `ARCHIVE_KEY` из 64 шестнадцатеричных символов. Сохраните этот ключ вместе с резервной копией базы. Каждый участник отдельно подключает свой Telegram через **Запись 24/7**. Это создаёт дополнительный сеанс Telegram на хостинге, который можно отключить в VeilGram или завершить в меню **Устройства** Telegram.

Сервер сохраняет текст и подписи новых входящих сообщений обычных чатов после подключения сеанса. Он держит до 2 000 ожидающих записей на аккаунт в течение семи дней и до 1 000 записей об удалениях. Тексты в SQLite и база сеансов зашифрованы. Секретные чаты, защищённый контент и сообщения с таймером исключены. Содержимое вложений сервер не загружает.

## Проверки

```sh
swiftc ios/VeilGramGiftLink.swift ios/PolusProfileService.swift scripts/check_profile_packets.swift -o /tmp/check-profile-packets
/tmp/check-profile-packets
```

Проверка пакетов покрывает кодирование оформления и подарков, отбрасывание повреждённых вложений и проверку идентификаторов. Патчи привязаны к коммиту Telegram-iOS `24638bc69bd083981b178dd1e7f921eebbf7fc46`. Сборка iOS и проверка интерфейса на iPhone требуют macOS с Xcode и тестового устройства.

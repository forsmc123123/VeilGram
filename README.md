# VeilGram для iPhone

Неофициальный нативный клиент на базе [Telegram-iOS](https://github.com/TelegramMessenger/Telegram-iOS). Минимальная версия для этой ветки — iOS 15.0.

- **Удалённые сообщения.** Когда клиент получает удаление уже загруженного входящего сообщения, он оставляет локальную копию на её месте. Пузырь полупрозрачный, рядом со временем есть корзина. Поддерживаются обычные личные чаты и группы, включая супергруппы. Копируются текст и подписи, а обычные вложения открываются из доступного кэша. Секретные чаты, сообщения с таймером, защищённый контент и сообщения, которых клиент ещё не получил, исключены.
- **Рамка аватарки.** В меню **Оформление VeilGram** можно выбрать цветовой пресет, фото, GIF или видео до 12 секунд. Видео в рамке проигрывается без звука. Там же меняются цвет имени и статус VeilGram.
- **Визуальные подарки.** Открой профиль подключённого участника и нажми **Подарить в VeilGram**. Клиент загружает обычные подарки из каталога Telegram и коллекционные по ссылкам `t.me/nft/…`. Оплата идёт с отдельного баланса VeilGram. После подключения на счёте 1000 визуальных звёзд. Обычная копия стоит 25, коллекционная — 100. В профиле видны шесть последних полученных подарков.
- **Оформление и голосовые.** Участники общего профиля видят значок VeilGram у имени в профиле и в личном чате. В настройках оформления есть дополнительная палитра чата и смена иконки приложения. Обычные загруженные голосовые можно расшифровывать средствами iPhone, если на устройстве доступно распознавание для текущего языка. Плашка VeilGram видна в самом приложении под камерой в портретной ориентации на моделях с высокой верхней областью экрана.

## Сборка с Windows и установка на iPhone

Пока проект содержит исходники и сценарий сборки. Готовый `.ipa` появится после успешной сборки на macOS.

1. Получите свои `api_id` и `api_hash` в разделе **API development tools**. [Инструкция Telegram](https://core.telegram.org/api/obtaining_api_id).
2. Загрузите проект вместе с `.github/workflows/ios.yml` в свой репозиторий GitHub. В **Settings → Secrets and variables → Actions** добавьте секреты `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`. Для общего оформления добавьте переменную `POLUS_PROFILE_ORIGIN`, например `https://profiles.example.com`.
3. В **Actions → Build VeilGram for iPhone** нажмите **Run workflow**. После успешной сборки скачайте артефакт `VeilGram-unsigned` и распакуйте `VeilGram-unsigned.ipa`.
4. Установите AltStore Classic через AltServer на Windows. Перенесите `.ipa` в приложение **Файлы** на iPhone и выберите его в **AltStore → My Apps → +**. AltStore подпишет и установит приложение. На iOS 16 и новее включите режим разработчика. С бесплатной учётной записью подпись нужно обновлять каждые семь дней. [Установка AltStore на Windows](https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows) · [Обновление подписи](https://faq.altstore.io/altstore-classic/your-altstore).

Можно собрать тот же `.ipa` на Mac с Xcode 27.1. Установите `ccache` и компонент `MetalToolchain` командой `xcodebuild -downloadComponent MetalToolchain`. Укажите `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` и, при необходимости, `POLUS_PROFILE_ORIGIN` в переменных окружения и запустите команду из папки проекта.

```sh
python3 scripts/build_ios.py ipa
```

Результат появится в `out/VeilGram-unsigned.ipa`. Для генерации проекта Xcode запустите `python3 scripts/build_ios.py xcode` с переменной `APPLE_TEAM_ID` вашей команды. В сборке для AltStore отключены расширения приложения. Доставка push-уведомлений на устройстве не проверена.

## Общее оформление

Для локальной рамки, цвета имени и статуса достаточно самого приложения. Для общего профиля, значков, визуальных звёзд и подарков оба пользователя подключаются к одному серверу VeilGram. Адрес можно указать в редакторе профиля или задать для сборки переменной `POLUS_PROFILE_ORIGIN`.

1. Создайте отдельного бота через [@BotFather](https://core.telegram.org/bots#how-do-i-create-a-bot). На сервере укажите токен в `server/.env` по примеру `server/.env.example`.
2. Направьте DNS-запись своего домена на сервер, укажите имя домена в `PROFILE_DOMAIN` и разрешите входящие порты 80 и 443. Из папки `server` выполните `docker compose up -d`. Caddy получит HTTPS-сертификат, а профильный сервис будет хранить данные в томе `profiles`.
3. В приложении откройте **Настройки → Оформление VeilGram → Сервер VeilGram** и укажите HTTPS-адрес. Откройте бота из редактора, нажмите **Запустить** с того же Telegram-аккаунта, введите полученный код и сохраните оформление.

Сервис хранит идентификаторы подключённых аккаунтов, выбранное оформление и медиа рамки, балансы и визуальные переводы. Копии удалённых сообщений и расшифровки VeilGram хранятся в локальной базе клиента. Для удаления рамки выберите **Без рамки** и сохраните оформление.

## Проверки

```sh
node --test server/profile.test.mjs
```

Тесты проверяют обмен оформлением между двумя аккаунтами, доступ к рамкам, ограничения одноразовых кодов и защиту от повторного списания визуальных звёзд. Патчи привязаны к коммиту Telegram-iOS `24638bc69bd083981b178dd1e7f921eebbf7fc46`. Сборка iOS и проверка интерфейса на iPhone требуют macOS с Xcode и тестового устройства.
